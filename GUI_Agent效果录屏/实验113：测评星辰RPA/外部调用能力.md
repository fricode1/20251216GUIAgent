# 目的

当用户在星辰RPA中编好了几个自动化脚本，该脚本如何被AI调用呢？

# 开放API

https://www.iflyrpa.com/docs/open-api/overview.html

通过 RESTful API 和 MCP 两种方式，为你的应用提供强大的 RPA 能力

## RESTful API

获取全部可用的 Workflow 列表，支持分页查询：GET https://newapi.iflyrpa.com/api/rpa-openapi/workflows/get

## MCP

https://newapi.iflyrpa.com/api/rpa-openapi/mcp?key={YOUR_API_KEY}

# 星辰 Agent 调用 RPA

https://www.iflyrpa.com/docs/agent/call-rpa.html

星辰Agent 平台原生集成了 星辰RPA，在 Agent 执行流程中动态调用 RPA 工作流。见《星辰Agent.md》
