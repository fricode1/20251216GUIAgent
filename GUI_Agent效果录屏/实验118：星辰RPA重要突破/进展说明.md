# 服务端安装

之前我装服务端报错：类别数量不匹配。但是王奇成功安装服务端。

王奇安装过程中也出现过问题：minio服务起不来。解决方案：更换了docker-compose.yml中minio的镜像名。

原始代码：

```yml
minio:
    image: minio/minio:RELEASE.2025-06-13T11-33-47Z-cpuv1
```

改为：

```yml
minio:
    image: minio/minio:RELEASE.2025-06-13T11-33-47Z
```
