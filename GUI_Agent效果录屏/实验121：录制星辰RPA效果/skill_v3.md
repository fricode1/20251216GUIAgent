# 火车票查询（RPA API）参考

当用户需要**查询火车票**、**寻找列车车次**或**了解某两地之间的火车票情况**时，应使用本 skill。该技能不需要编写代码，而是通过在 Shell/CMD 中执行预置好的本地 Python 脚本来触发后台 RPA（机器人流程自动化）查询。

## 何时使用

- 用户说：「帮我查一下明天从福州到北京的火车票」
- 用户说：「2026年3月28日去北京的高铁有哪些？」
- 用户需要获取指定日期、指定出发地和目的地的列车信息。

*注意：如果用户没有提供完整的“出发地”、“到达地”和“出发时间”，请先向用户询问补齐这些信息，再执行查询。*

## 使用方式（执行本地脚本）

请在 Shell/CMD 环境中，直接调用现成脚本 `rpa_12306.py`，并将用户提供的参数按顺序传入。

`C:\Users\admin\Documents\GitHub\fri\20251216GUIAgent\GUI_Agent效果录屏\实验121：录制星辰RPA效果\rpa_12306.py`

**命令格式：**
请务必使用双引号将脚本路径和所有参数包裹起来：
```cmd
python "C:\Users\admin\Documents\GitHub\fri\20251216GUIAgent\GUI_Agent效果录屏\实验121：录制星辰RPA效果\rpa_12306.py" "<出发地>" "<到达地>" "<出发时间>"

```

## 响应处理与结果解析

脚本执行完毕后，控制台会打印出状态码和 JSON 格式的响应数据。请根据打印出的 `响应: {...}` 数据判断执行状态，并向用户反馈：

### 情况1：查询成功
当响应 JSON 中的 `data.execution.status` 为 `"COMPLETED"` 时，表示 RPA 查询成功。
- **解析路径**：提取 `data.execution.result.data.output_variable` 的值。
- **示例数据**：`"output_variable": "G964智复静查看票价"`
- **反馈用户**：将提取到的车次和票务信息自然地播报给用户（例如：“为您查到相关车次信息：G964...”）。

### 情况2：RPA 客户端未启动 (失败)
当响应 JSON 中的 `data.execution.status` 为 `"FAILED"`，且 `data.execution.error` 包含 `"send uuid empty"` 时，表示后台运行环境异常。
- **反馈用户**：告知用户：“当前后台 RPA 客户端未启动，请先检查并启动 RPA 客户端后再试。”

## 注意

1. **日期格式**：传入脚本的第三个参数必须是 `YYYY-MM-DD` 格式。如果用户说“明天”，请先根据当前时间计算出准确的日期字符串后再作为参数传入。
2. **路径与参数引号**：由于脚本的绝对路径中包含中文，在生成命令时，请**务必使用双引号** `" "` 将路径和三个参数分别包裹起来，防止解析错误。
3. **超时机制**：RPA 执行通常需要一定时间，在执行命令前可先回复提示用户：“正在为您启动后台查询，请稍候...”。
